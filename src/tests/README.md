# Regression tests

From `src/`, run `npm test` (`npm.cmd test` in Windows PowerShell). The Node suite uses DOM stand-ins for UI/session actions. It checks tree operations, serialization, rendering markup, and state transitions; it does not exercise a real browser.

## Pinned re-rooting fixtures

`fixtures/reroot_validation/` is a byte-for-byte copy of the self-contained fixtures and validator supplied from `ARPP/Fig2/trees/reroot_validation/`. The accompanying report is preserved in `fixtures/reroot_bug_report.md`. Fixture files and `validate_reroot.py` are unchanged; they must stay pinned when the upstream pipeline regenerates its other trees.

The JavaScript tests compare canonical bipartitions, lengths, and every support representation, including both children of a bifurcating root. They verify the source depths (RLP 10, XI 3, XII 5), support counts (288/203/177), outgroup stem lengths, and basal tip counts (2/289, 49/157, 5/175). The same invariants are checked after export/reparse, session loading, and the UI action's undo/redo.

The known-buggy RLP fixture is a required negative control: tip set, topology, total length, and per-bipartition lengths pass; support, root-edge splitting, outgroup placement, and root metadata fail. This prevents topology-only testing from accepting the original bug again.

## Independent Python validator

Run `npm run test:reroot-validator` from `src/`. Requires a Python environment with `ete3` installed. The runner uses `python` by default; the `PHYLOSCOPE_PYTHON` environment variable can specify another executable. The app itself remains browser-only, and the regular Node test suite does not require Python.

The runner invokes the supplied checker unchanged, first on all three expected outputs and the buggy RLP output, then on outputs generated by PhyloScope. It requires:

- Expected RLP/XI/XII: 8/8, exit 0.
- Buggy RLP: 4/8, exit 1, with failures exactly at checks 4, 6, 7, and 8.
- Generated RLP/XI/XII: 8/8, exit 0.

Generated Newick files and complete validator logs are retained in a uniquely named temporary directory printed by the runner. The checker uses ete3 to parse and compare topology, never to perform the re-rooting under test.

## Root-edge representation

PhyloScope splits the selected stem at its numeric midpoint and assigns the second half as `length - firstHalf`, retaining the summed length without output rounding. Both children carry the stem support. The fixture's known-good files round the root halves to six decimal places; comparison is by the original bipartition and summed root-edge length, not byte-identical Newick text. Preserving source trailing zeros and adding a final newline remain separate export-formatting tasks in `plan.md`.
